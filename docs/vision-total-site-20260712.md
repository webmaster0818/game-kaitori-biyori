# ゲーム買取びより：総合ゲーム買取サイトの理想像と実行計画（2026-07-12策定）

## 0. 現状の地力（GSC直近28日）
- 154click / 2,454imp（成長中）。**勝ち筋は完全に実証済み**：
  - 業者レビュー（信頼不安クエリ）＝ウリエル85click/CTR12%・カイトリワールド56click・ホビーコレクト31click・ゲーム王国21click・ゲオ10click
  - software/high-value 23click/CTR11%（高額タイトルの買取相場）
  - compare/mercari-vs-kaitori 14click
- 構成：review19・compare5・hardware9・software12・area12・knowledge13・method4・price-index・condition-guide

## 1. 理想像（Vision）
> **「ゲームを売る人が、①この業者は怪しくないか ②今どこが一番高く買うか ③自分の商品・状態・地域で最適な売り方、を1サイトで完結できる。実測データに基づく“日本一信頼できるゲーム買取の総合ナビ”」**

### 3本柱
1. **信頼（不安解消）**＝業者レビュー：古物商許可・運営会社・手数料・実態を「結論ファースト」で提示。市場需要の44%を占める「評判/口コミ/怪しい/詐欺」不安クエリを安心に変える（ウリエル型で実証）。
2. **データ（最高値がわかる）**＝price-index：**毎週実測の買取価格DB**。「今どこが一番高い」を実データで答える唯一のサイト。これが競合が真似できない“堀”。
3. **網羅（総合性）**＝6軸を相互リンクで網羅：業者×商品×手段×状態×エリア×知識。

## 2. 実行計画（優先順位付き）

### P0【最速回収・最大レバー】高表示レビューのCTR最適化
「表示は桁違いなのに刈れていない」ページをウリエル型（CTR12%）に寄せる：
- カイトリワールド **2,988imp/CTR1.9%/pos6.1** ← 最大の取りこぼし
- ホビーコレクト **1,475imp/CTR2.1%**・ヒカカク **922imp/CTR0.7%**・ゲーム王国 756imp
- 打ち手：title/冒頭に「古物商許可番号＋結論（正規事業者）＋怪しい理由の正直分解」を強化、手数料4点表、別名（メディアワールド等）セクション。
- 試算：CTR1.9%→5%で**カイトリワールドだけで月+90click**。3ページで月+150〜200click規模。

### P1【堀を広げる】price-indexの拡張と主役化
- 対象拡大：人気ソフト・レトロ・ハード・周辺機器の実測を追加し「〇〇 買取 いくら/相場」の受け皿に。
- 主役化：全レビュー・比較から price-index へ「今どこが一番高いか確認」CTAを徹底。
- ヘッド接続：「ゲーム買取 どこがいい/高い」比較ヘッドの結論を price-index に接続。

### P2【網羅性】6軸の穴埋め
- 業者軸：指名需要を検証した実在業者を追加（Phase2継続）＋手数料4点表を全業者へ統一。
- 商品軸：hardware/software の主要タイトル買取相場を拡充。
- 手段/状態/エリア軸：既存を強化＋相互内部リンク網。

### P3【比較ハブ】/compare/ 強化
- which-is-best を結論ファースト＋price-index接続。用途別（宅配/店頭/出張・高価格/手軽さ）の比較表。

### P4【鮮度・信頼運用（E-E-A-T）】
- 毎週価格更新（生命線）＋【年月】鮮度＋確認日。実測・古物商・一次情報で信頼性を担保。

### P5【CV動線】
- 「不安クエリ→安心レビュー→price-indexで最高値→業者へ」を全ページで貫通。

## 3. 測定と運用
- 週次価格更新時にGSCでCTR/pos/clickを判定 → 勝ち型を横展開（既存の計測ゲート運用を継続）。
- KPI：総click・不安クエリCTR・price-index経由の送客・指名レビューの順位。

## 4. 90日ロードマップ（目安）
- 〜2週：P0（高表示3レビューのCTR最適化）→初動判定
- 〜1ヶ月：P1（price-index拡張＋送客動線）
- 〜2ヶ月：P2（業者・商品軸の網羅）＋P3（比較ハブ）
- 〜3ヶ月：全軸の内部リンク網完成＋鮮度運用の定着 → “総合ナビ”として確立

## G案で適用した値
- 本文 14px / 行21px / 字間 **-0.2px**、ウエイトは **300/400/500のみ**
- サイズは 12/13/14/15/20/25/31/39/52px の整数スケール
- 色は 白・#1F1F1F・#6B6B6B・暗面#0E1317・アクセント1色 の**5つだけ**（文字に色を使わない）
- 角丸 **4/8/16/32px**、完全な円はボタン形状のみ
- コンテンツ幅 1320px固定、暗い帯と画像は1440px全幅
- 金額は `tabular-nums` で桁を揃える

## 構造の置き換え
PSの「暗い帯のゲームタイル格子」→ **今週の最高値タイル（12マス）**。
このサイトの資産である週次実測DBを、最も機械的に見せられる形。
※ゲームのパッケージ画像は権利上使えないため、タイルは**金額を主役**にした。
